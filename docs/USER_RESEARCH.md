# 用户研究与问题证据

> 版本：2026-10-11  
> 研究原则：不以“多数散户亏损”制造焦虑，不把相关性写成因果，不虚构访谈、样本或产品效果。

## 1. 先给结论：值得解决的不是“帮散户赚钱”

本产品选择的问题是：**自主投资者很难把跨来源研究、当时的投资判断、后续新事实和真实执行保存在同一条可回查的链路上。**

它造成的直接损失不是一个未经证实的“平均亏损率”，而是四种可以在工作流中观察和测量的浪费：

1. 每次研究同一公司都从头搜索，历史判断无法复用；
2. 财报、公告、行情、卖方观点和新闻口径不同，结论难以回查；
3. 买入时的 Thesis、条件和计划没有冻结，事后容易用新信息改写旧判断；
4. 复盘只看盈亏，难以区分研究错误、执行偏差、风险控制问题和正常波动。

因此，自渡不承诺提高收益，而是把研究与复盘变成**更快、可追溯、可连续更新、能积累个人经验**的流程。

## 2. 目标用户与边界

### 核心用户

有两年以上 A 股投资经验、会主动研究公司或产业、同时使用多个信息源，并愿意记录投资逻辑的个人投资者。

### 不优先服务

- 只希望获得股票代码或短线买卖指令的用户；
- 需要机构级全市场实时终端、组合风控或自动交易的团队；
- 不愿意确认个人判断、只希望模型替自己负责的用户。

### Job to Be Done

> 当我研究并交易一家公司时，我希望 Agent 帮我把公开信息组织成可验证的判断，保存“我当时为什么这么想”，并在新事实或成交出现后对照复盘，这样我不必反复从零开始，也不会在事后改写自己的逻辑。

## 3. 公开证据：用户规模大，但盈亏不是产品论据

### 3.1 市场规模

中国结算 2025 年统计年报显示，2025 年末投资者数量为 **25,067.29 万**，全年新增 **1,386.95 万**。这是“个人投资工作流”具有足够用户基数的证据，不代表这些用户都需要本产品，也不代表活跃自主研究者的实际规模。[证券时报经东方财富转载，2026-06-13](https://fund.eastmoney.com/a/202606133770584522.html)

### 3.2 盈亏数据只能描述样本，不能证明产品因果

上海证券报 2026 年第三季度个人投资者调查称，受访者在 2026 年二季度 **44% 盈利、30% 亏损、26% 持平**；同一调查还显示 65% 的受访者在二季度末买入科技股。文章未披露可用于外推总体的完整抽样框、样本量与加权方法，因此本文只写“受访者”，不写“A 股投资者总体”。[上海证券报，2026-08-10](https://paper.cnstock.com/html/2026-08/10/content_2253508.htm)

同一系列调查对 2025 年全年给出的结果是 **57% 盈利、19% 亏损、24% 持平**。这说明盈亏比例会随统计区间、行情和样本显著变化，不能用单一数字证明“散户普遍亏损”。[上海证券报，2026-02-02](https://paper.cnstock.com/html/2026-02/02/content_2177144.htm)

东方财富财富号中还出现“2026 上半年 79%–82% 活跃个人投资者亏损”等说法，但正文没有给出可回查的一手报告、抽样方法或样本量。此类内容只能作为“信息质量参差、用户需要核验来源”的案例，**不得作为产品立项数据**。[东方财富财富号，2026-07-17](https://caifuhao.eastmoney.com/news/20260717083438693528010)

### 3.3 研究信息与投资行为确实存在关联，但不是收益承诺

深交所 2020 年个人投资者调查覆盖 31 个省级行政区、342 个城市，收到 27,667 份有效问卷。盈利投资者阅读金融机构研究报告、上市公司定期/临时公告的比例，分别比亏损投资者高 11.3 和 7.4 个百分点。它支持“高质量信息处理值得改善”，但仍是相关关系，不能推导“使用本产品必然盈利”。[深交所，2021-05-17](https://www.szse.cn/www/investor/institute/bookshelf/report/t20210519_585972.html)

证监会转述 IOSCO 行为研究指出，情绪、经验法则以及对信息的部分评估与完整评估会影响散户决策。这为“保存事前判断、结构化检查证据和复盘执行”提供行为层面的合理性，但不等同于产品效果验证。[中国证监会，2019-07-23](https://www.csrc.gov.cn/csrc/c100220/c1003100/content.shtml)

## 4. 现有工作流与断点

现状流程：

> 看到新闻/观点 → 在行情软件、搜索引擎、公告、财报、社区之间切换 → 在聊天模型或零散笔记中形成当下看法 → 下单或观望 → 新信息出现后重新搜索 → 原判断、来源和时间口径逐渐丢失 → 看盈亏做事后解释。

关键断点不是缺少某个搜索框，而是：

| 断点 | 现有替代方式 | 仍未解决 |
|---|---|---|
| 信息分散 | 行情终端 + 搜索 + 社区 | 来源等级、时间口径、冲突和缺口没有统一表达 |
| 问答一次性 | 通用聊天模型 | 不知道历史 Thesis，也不会稳定维护公司/行业档案 |
| 研究与行动断开 | 笔记或自选股备注 | 事前条件、决策版本和成交没有结构化关联 |
| 复盘只看结果 | 收益曲线、交易软件交割单 | 不能区分研究、执行、风控和环境因素 |
| 个人经验难复用 | 手写规则 | 不知道规则来自哪些案例，也缺少用户确认门槛 |

## 5. 真实产品观察：长期自用 N=1

产品作者是目标工作流的长期使用者。开发过程中保存了真实输入、界面反馈和脱敏 BadCase；它们能够证明问题真实发生，但 **N=1 不能代表整个用户群体**。

### 已观察到的高频失败

| 用户任务 | 第一版失败 | 暴露的问题 | 通用产品修复 |
|---|---|---|---|
| “今天盘面如何” | 固定 Router 直接读旧看板 | 没有先判断数据新鲜度 | Planner 先检查时点和数据覆盖，再决定刷新、回答或降级 |
| “完整研究东方锆业” | 搜到几条材料即停止 | 搜索轮数代替研究完成度 | Coverage Checker 按研究问题检查证据缺口，而非固定轮数 |
| “东山精密市场预期” | 公司指引、卖方目标和叙事为空 | 只搜财报，来源通道过窄 | 将管理层、卖方、市场叙事作为独立证据通道并并行补搜 |
| “AI 安全事件如何影响投资” | 被当成公司研究或泛搜索 | Router 只识别股票和行业关键词 | 增加 Event / Theme 研究对象，先做定义、时间线、传导链和受益受损验证 |
| 复盘一笔交易 | 只根据当前盈亏总结 | 事后信息污染事前判断 | 冻结 Entry Thesis，分别比较新事实、执行和结果 |

其中两个案例已进入仓库的可回归资产：

- **evals/research/bad_cases/dongshan_sell_side_expectations_missing/**；
- **evals/research/bad_cases/ai_safety_theme_misclassified/**。

这些案例证明的不是“模型已经完美”，而是产品可以把失败从一次抱怨转成可复现、可修复、可回归的工程资产。

## 6. 证据 → 产品能力映射

| 证据或观察 | 产品判断 | 对应能力 | 如何验证 |
|---|---|---|---|
| 用户基数大 | 有足够潜在用户，但目标群须继续收窄 | 面向自主研究者而非所有股民 | 招募时用研究频率和记录习惯筛选 |
| 盈亏口径互相冲突 | 产品不能靠恐惧营销，也不能把搜索摘要当事实 | Source → Evidence → Claim 引用链 | 随机抽取数字回查原文、日期、单位、口径 |
| 盈利者更常阅读研报/披露（相关性） | 提升证据处理效率有合理价值 | 多来源研究 Skill + Coverage Checker | 对比人工流程的时间与关键项遗漏率 |
| 行为偏差影响决策 | 事前冻结和事后对照值得做 | Decision 确认门 + Review 归因 | 检查未确认判断不得写入；复盘能找到原版本 |
| N=1 BadCase 反复发生 | 单次 Prompt 不能稳定承担完整流程 | Planner、Tools、Memory、Policy、HITL | BadCase 修复后进入回归 Eval |

## 7. 现在已经知道什么，还不知道什么

### 已有证据支持

- 中国证券市场有大规模个人投资者群体；
- 投资者会面对来源、口径、时间和质量不同的信息；
- 信息处理方式与决策行为值得改进；
- 在本产品的长期自用中，研究完整度、历史连续性和事前/事后隔离是反复出现的真实问题；
- Agent 能通过工具调用、状态和检查器把部分失败转为可测流程。

### 尚未验证，不在本次材料中冒充结论

- 有多少投资者愿意长期记录 Thesis 和复盘；
- 除作者之外，用户是否能无教学完成完整闭环；
- 产品能否提高真实投资收益；
- 哪种研究深度与等待时间最匹配不同用户；
- 付费意愿和最合适的商业模式。

## 8. 后续验证方案

在可运行 Demo 完成后，招募 3–5 名符合核心用户条件的测试者，每人完成同一个公开公司任务：

1. 找出公司最近三年收入/利润变化、一个核心 Thesis、两项反证和一个待验证指标；
2. 保存一条模拟 Decision；
3. 在给定“新财报 + 模拟成交”后完成一次 Review。

只测工作流价值，不测短期收益：

| 指标 | 定义 | 目标（待实测，不是当前结果） |
|---|---|---:|
| 首次任务完成率 | 无人工接管完成研究→决策→复盘 | ≥ 80% |
| 关键项遗漏率 | 标准答案中的必要研究项未覆盖比例 | 比纯手工流程下降 |
| 数字可回查率 | 抽样数字能回到原文、日期、单位、口径 | 100% |
| 历史判断找回率 | Review 能正确加载事前 Thesis 版本 | 100% |
| 完成时间 | 从问题到可保存研究档案的中位时间 | 比同一用户手工流程更短 |
| 主观可用性 | 5 分量表：是否愿意下次继续使用 | ≥ 4.0 |

若测试尚未完成，提交材料中显示“待实测”，不预填通过结果。
