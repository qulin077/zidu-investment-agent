# 东山精密卖方预期缺失

这个案例记录“检索很多，但市场预期仍为空”的失败。根因不是简单的网页少，而是公司资讯分支发生静默异常、卖方来源排序错误、目标价事实被误过滤，以及财务优先的 claim 截断共同造成。

修复后的边界是：产品不提供自己的目标价或买卖建议；但对花旗等具名机构已经发布的目标价、评级与盈利预测，必须按来源等级和日期保留，并展示后续修订。iFinD 语义片段只能作为 `VENDOR_EXCERPT`，不能冒充研报全文。

本案例进一步记录了一个容易混淆的数字：已核对材料中的 `282.28 亿元`是东方证券对东山精密 2028 年归母净利润的预测，不是花旗目标价。截至 2026-10-07 的定向查询未找到花旗在 350 元后改为 282 元的可靠记录，因此产品应显示“未核实”，不能把相似数字自动串成修订时间线。

运行 `python -m evals.research.runner` 可验证搜索合同、目标价证据边界和修订时间线。
