# 卖方预期与修订时间线

公司研究不能把“没打开研报”写成“没有市场预期”。卖方通道分别记录发现、读取和验证状态。

## 来源阶梯

1. 原始研报正文或合法可读的报告页：可直接记录预测、评级、目标价、估值方法和假设。
2. 数据商返回的带日期语义片段：可作为 `VENDOR_EXCERPT` 线索，必须保留原始 URL，并继续回溯。
3. 媒体对研报的明确转述：可作为二手证据，必须写明“媒体转述”。
4. 评级聚合页：适合核对机构、日期、目标价修订序列，不单独证明报告里的经营假设。
5. 社区文章或截图解读：只保存为市场叙事或待核线索，不能冒充原始研报。

## 检索动作

首轮至少并行执行：

- 公司名/代码 + 券商研报 + 盈利预测 + 一致预期；
- 公司名/代码 + 花旗/高盛/瑞银/摩根等常见外资机构 + 目标价 + 评级 + 上调/下调；
- 公司名/代码 + 分析师评级 + 目标价 + 盈利预测 + 预期修订；
- iFinD 公司资讯语义检索：卖方预期修订；
- iFinD 公司资讯语义检索：催化、市场预期与争议。

候选按“相关性 → 日期倒序 → 来源等级”排列。不得按 URL 字母顺序打开。某目录返回大量旧报告时，
不得让旧 PDF 挤占最新材料的读取预算。

## 结构化字段

```text
institution
report_date
rating
target_price
forecast_period
revenue_forecast
profit_forecast
eps_forecast
valuation_method
key_assumptions
revision_direction
previous_value
current_value
source_grade
source_url
original_report_status
```

同一机构的新报告不会覆盖旧报告。按日期形成时间线，并将旧记录标成 `HISTORICAL`、最新可见记录标成
`LATEST_VISIBLE`。若后续二手来源显示新值但原始报告未打开，写“最新公开线索”，不要写“已确认最新”。

## 研究输出

市场预期至少分为：

- 公司指引；
- 一致预期；
- 卖方预测；
- 市场叙事；
- 预期修订时间线。

目标价是卖方观点，不是产品建议。展示时同时给出日期、机构、估值方法、核心假设和来源等级；没有这些
上下文时，孤立目标价没有研究价值。

## 完成与失败语义

- `PASS`：至少打开一份可核对卖方正文，或取得带机构、日期、期间的可靠预测数据。
- `PARTIAL`：只有数据商片段、媒体转述或聚合评级，尚未打开原始研报。
- `ATTEMPTED_UNAVAILABLE`：搜到候选但全部打不开或解析失败。
- `MISSING`：该来源动作根本没有执行。

`ATTEMPTED_UNAVAILABLE` 和 `MISSING` 都不能被表述为“没有券商覆盖”。
